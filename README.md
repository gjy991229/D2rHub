## 🇨🇳 中文说明 (Chinese)

D2Hub 是一款专为《暗黑破坏神 II：重制版》(D2R) 玩家精心设计的**多账号管理与一键多开助手**。无论是多账号挂机、装备倒腾，还是多角色配置管理，它都能让您的游戏体验变得无比轻松和高效。

### ✨ 核心特色功能
*   **🎮 真正的安全多开**：一键自动清除游戏的多开限制。**不修改游戏任何文件、不注入任何游戏内存**，完全基于 Windows 标准进程句柄清理技术，绿色安全，无封号风险。
*   **🚀 账号独立配置**：每个账号可以绑定不同的战网账号、独立的启动参数（支持不同 Mod），以及**独立的存档目录**（大号和小号的单机存档再也不会搞混了！）。
*   **⚙️ 图形化画质设置**：内置全中文画质编辑器。您可以为不同账号设置不同的画面等级，例如：大号开“超高画质”尽享视觉盛宴，挂机小号一键应用“极低画质预设”，大幅节省显卡和 CPU 资源。
*   **📊 电脑硬件监控**：实时监控您的 CPU、内存、显卡占用以及显存（VRAM）使用情况，挂多个号时电脑撑不撑得住一目了然。
*   **🪟 迷你悬浮窗 (Overlay)**：当主窗口最小化或游戏启动后，会在桌面边缘显示一个精美的半透明悬浮窗，展示当前游戏账号状态及电脑硬件负载。
*   **🐱 桌面键盘猫咪 (Bongo Cat)**：自带会敲键盘的桌面萌宠猫咪！当您在游戏内击杀怪物、爆出神符/暗金装备时，猫咪还会触发特殊的惊喜掉落动画，陪您一起刷刷刷！

### 🛠️ 快速上手步骤
1.  **下载软件**：前往 [Releases 页面](https://github.com/gjy991229/D2rHub/releases) 下载最新的版本。
    *   *安装包版（推荐）*：下载 `d2hub-setup.msi`，双击安装即可。
    *   *免安装版*：直接下载 `d2hub.exe` 运行。
2.  **首次运行配置**：启动 D2Hub，设置向导会自动扫描并帮您填写好战网客户端路径、游戏目录以及存档路径，确认无误后点击“保存并继续”。
3.  **添加与启动账号**：
    *   点击主界面的“添加账号”，输入您的账号别名。
    *   点击“初始化”，软件会自动关联您当前的战网和游戏配置。
    *   勾选想要启动的账号，点击“一键启动”，软件就会帮您自动排队登录并清除多开限制！

### 🛡️ 安全承诺
D2Hub 本质上是一个“配置与窗口管理器”，它通过 Windows 系统的 API 关闭 D2R.exe 的检测限制，**不修改任何游戏内存，不注入任何 DLL 补丁**，属于 100% 绿色安全的辅助工具。

## 🇺🇸 English Description

D2Hub is a lightweight, player-friendly Windows utility designed for managing multiple accounts and enabling multi-boxing (multi-clienting) in **Diablo II: Resurrected (D2R)**.

### ✨ Features
*   **🎮 Safe Multi-Instance (Multi-Boxing)**: Bypass the D2R single-instance restriction automatically. D2Hub uses native Windows API handle closing technology — **no memory injection, no modified game files, 100% safe**.
*   **🚀 Configuration Isolation**: Bind different Battle.net accounts, custom launch arguments (Mod support), and **independent save directories** for each profile.
*   **⚙️ Graphical Settings Editor**: Tweak D2R's `Settings.json` with a full GUI. Apply graphics presets instantly (e.g., Ultra settings for your main character, Minimum settings for alt accounts to save GPU/CPU resources).
*   **📊 Hardware Load Monitor**: Real-time tracking of CPU, RAM, GPU, and Video Memory (VRAM) so you can monitor your computer's health while multi-boxing.
*   **🪟 Desktop Overlay**: A compact, semi-transparent overlay shows on the edge of your screen when the manager is minimized, showing hardware stats and active account status.
*   **🐱 Interactive Bongo Cat**: A cute animated desktop pet that mimics your keyboard strokes! It triggers unique visual animations when high-value loot (Uniques/Runes) drops in the game.

### 🛠️ Quick Start
1.  **Download**: Get the latest version from the [Releases](https://github.com/gjy991229/D2rHub/releases) page (MSI installer or standalone EXE).
2.  **First Run**: The wizard will auto-detect your Battle.net, D2R game path, and save folders. Click **Save & Continue**.
3.  **Manage Profiles**: Click **Add Account**, name it, click **Initialize**, select the accounts you wish to launch, and click **Launch**. D2Hub handles the login queue and clears the mutexes automatically.
