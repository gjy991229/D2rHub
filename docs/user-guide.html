CURRENT MANUAL · 2026-08

D2RHub v0.9
使用手册

面向当前 0.9.x 统一桌面版本的完整操作说明，覆盖国服/国际服双客户端、多账号认证、音频声纹、悬浮窗与本地统计。

适用版本 v0.9.x Windows 11 Audio Telemetry 本地数据

统一桌面版本

D2RHub 只维护一个功能完整的桌面版本，默认包含账号管理、多开、画质设置、音频声纹、统计页、悬浮窗和桌宠。MSI 与 NSIS 使用相同代码和功能，只是安装格式不同。

01 · FIRST RUN

快速开始

下载并安装

从项目 Releases 下载 MSI / NSIS 安装包，完成安装后启动 D2RHub。

至少配置一套客户端档案

在首次向导中填写国服或国际服的“游戏目录 + 存档目录”。使用战网认证时，再填写该客户端的 Battle.net.exe。

创建账号

点击“添加账号”，依次选择昵称、区服、语言和认证方式。网页 Token 按向导取得并粘贴；战网认证按提示完成登录与快照。

启动

在账号卡片启动单个账号，使用“启动全部”依次处理所有可用账号，或创建并复用命名启动方案。常用方案可以固定在主界面直接启动；启动进度和错误会显示在卡片及运行日志中。

一键准备并开启识别

在“设置中心 → 自动化”选择已初始化账号，再选择“我玩原版”或一个现有 Mod，并为生成的新 Mod 输入名称，点击“一键准备并开启”。无论是否使用源 Mod，名称都为必填，仅可使用英文字母、数字、短横线和下划线。D2RHub 会生成并复核新的识别 Mod，同时为该账号配置 -mod <名称> -txt -assettestmode 1；游戏已运行时需重启该账号一次。

路径检测边界：当前向导可自动探测国服/国际服存档目录、Agent、Roaming 配置和 Edge/Chrome；游戏安装目录及 Battle.net.exe 仍应由你确认或手动选择。

02 · CONNECTIONS

路径与双客户端配置

“设置中心 → 连接”把本机环境分为两套互不混用的安装档案。

CN PROFILE

国服

供国服账号使用。存档目录通常带有 Diablo II Resurrected (CN) 标识。

GLOBAL PROFILE

国际服

亚服、 美服和欧服共用同一套国际服游戏、战网和存档路径。

每套档案需要什么

  • 游戏安装目录：包含 D2R.exe，任何认证方式都需要。
  • 存档目录：包含或将包含 Settings.json，任何认证方式都需要。
  • Battle.net.exe：仅战网客户端认证需要；全部账号都用网页 Token 时可以留空。

如果存档目录暂时没有 Settings.json，账号创建、登录和多开仍可用，但画质编辑、账号独立游戏配置和系统配置快照不可用。先用对应客户端正常进入一次游戏，通常会生成该文件。

辅助路径

Agent 目录和 %APPDATA%\Battle.net 用于战网运行环境切换；Edge / Chrome 用于网页 Token 的独立浏览器档案。浏览器不是游戏启动的必需项，但使用内置 Token 获取流程时应配置。

03 · ACCOUNTS

账号与认证

添加账号向导顺序为：昵称 → 区服/语言/配音 → 认证模式 → 获取 Token → 粘贴 Token。选择战网认证后，流程会改为客户端登录、采集本地认证快照并清理临时状态。

方式网页 Token（推荐）战网客户端认证
所需路径游戏 + 存档；获取时需 Edge/Chrome游戏 + 存档 + 对应版本 Battle.net.exe
启动路径使用本机 DPAPI 加密保存的 Token 直启恢复账号的 Battle.net / UnifiedAuth 本地快照后启动
特点启动快，不依赖战网客户端常驻适合无法使用网页 Token 的账号，流程更长
失效处理服务端判定失效时，在账号操作中更新 Token界面按 30 天提示有效状态；过期或登录失败时重新初始化
凭据安全：Token 经 Windows DPAPI 绑定当前 Windows 用户后落盘。它仍属于敏感凭据，不要复制到 Issue、聊天记录或截图中，也不要分享账号目录。

账号卡片可以做什么

  • 启动账号、只启动 Battle.net（战网认证账号）、更新 Token 或重新初始化。
  • 修改昵称、区服/认证信息、Mod 启动参数与常用参数列表。
  • 设置游戏窗口 X/Y 位置，切换系统配置或账号独立配置。
  • 展开快速设置修改分辨率和帧率；拖动卡片可改变账号顺序，快捷键位置会随顺序对应。

04 · LAUNCH

启动方案与进程控制

  • 单账号：点击账号卡片的启动按钮。
  • 启动全部：按当前账号顺序依次处理所有可启动账号。
  • 启动方案：从工具栏展开已保存的账号组合并直接启动；同一账号可以加入多个方案。
  • 常用方案：在“启动方案”菜单中点击方案右侧的星标，可将其固定在“启动方案”和“一键关闭”之间；点击固定按钮即可直接启动，再次点击星标可移除。
  • 编辑启动方案：新建或编辑时填写方案名并勾选账号，再明确保存。取消编辑不会改变原配置；新增账号不会自动加入已有方案。
  • 启动前检查：启动顺序跟随账号卡片当前排序；只要方案内存在未初始化、已删除或需要迁移 Token 的账号，整个方案启动都会被阻止并提示先处理。
  • 取消：启动队列运行时可以取消；程序会尽量收束本轮产生的战网/认证临时状态。
  • 窗口聚焦：使用已绑定快捷键，或在展开悬浮窗双击账号名称。
“一键关闭”是强制操作：它会结束当前系统内所有 D2R.exe 进程，可能造成未保存的游戏进度丢失。确认所有游戏都可以退出后再执行。

多开通过 Windows 进程与句柄管理完成，不修改游戏文件、不写入游戏内存，也不注入 DLL；但第三方工具仍可能受到游戏条款、反作弊策略、系统权限或安全软件影响，请自行评估风险。

05 · SETTINGS CENTER

设置中心速查

连接国服/国际服游戏、战网、存档、Agent、Roaming 与浏览器路径
账号昵称、启动方式、Mod、窗口位置、分辨率、帧率与完整游戏设置
启动策略Agent 延时杀、进程数阈值或不处理；隔离浏览器和每日更新
快捷键按账号当前位置绑定全局聚焦组合键
显示界面语言、主题、主窗口/悬浮窗透明度、字体和悬浮窗开关
自动化声纹接收、追踪类别、目标账号、识别阈值、诊断与统计页
伴随Bongo Cat 开关、对话框、缩放和已解锁皮肤
维护打开日志目录、重新运行首次配置向导

账号独立游戏设置

选中已初始化账号后，可编辑启动、显示、图形、音频、玩法和地图设置。修改会自动保存。选择“系统配置”时跟随当前存档目录的 Settings.json；选择独立配置后，该账号保留自己的快照。需要以当前系统设置为基准时，使用“快照系统配置到当前账号”。

06 · PERFORMANCE OVERLAY

性能悬浮窗

悬浮窗常驻桌面上方，可显示运行账号、当前场景、刷图计时和所选掉落。场景统计窗口会把同类物品合并为 #15 海尔 ×2 一类的计数胶囊；刚识别的掉落会在分组列表上方短时弹出，最多同时显示 3 种。分组列表默认显示最近 5 种，点击“展开其余”可查看全部，再次点击即可收起。

分组右侧的删除按钮只移除该组最近一次掉落。统计悬浮窗也支持贴边自动隐藏，但始终保持完整布局，不切换迷你模式。关闭场景统计窗口只会隐藏界面；只要“音频声纹自动识别”仍处于开启状态，按进程捕获、计时与落库会继续运行。

展开与迷你

  • 展开模式双击空白区域，或迷你模式双击悬浮窗，可切换模式。
  • 窗口获得焦点时按 Enter 或 Space 也可切换。
  • 展开和迷你模式分别记住尺寸；展开模式双击账号可聚焦对应游戏。
  • 迷你双层布局最低为 36 逻辑像素；继续向下缩放会切成单行，最低为 18 逻辑像素。拉高到阈值会恢复双层；高 DPI / 2K 屏会按系统缩放正确换算。

贴边吸附与自动隐藏

  1. 把 TZ 悬浮窗或统计悬浮窗拖到屏幕任一边缘并松开。
  2. 窗口会吸附到最近边缘并平滑推入屏幕外，只保留一条约 8px 的触发边。
  3. 把鼠标移到触发边，窗口会平滑抽出；鼠标离开后再次推入隐藏。
  4. 窗口抽出时向屏幕内部拖走，即可取消吸附。

吸附位置按当前显示器的可用工作区计算，也适用于副屏和任务栏占用区域。系统启用“减少动态效果”时，抽出/隐藏会改为即时完成。

07 · AUDIO TELEMETRY

独立 Mod 工具与实时识别

识别 Mod 由无界面的 d2r-audio-mod.exe 独立生成，D2RHub 负责调用生成器、复核输出、配置目标账号，并接收和统计 v7 声纹。生成器不读取 D2RHub 的账号、配置或数据库，也不修改源 Mod。“设置中心 → 自动化”选择一个已初始化账号后，捕获器只监听该账号的 D2R 进程及其子进程。

  • 两种准备方式：选择“我玩原版”时从本机游戏资源创建识别 Mod；选择“我使用 Mod”时复制并加工所选现有 Mod，保留其功能且不修改源目录。两种方式都需要为输出的新 Mod 输入名称。
  • 兼容处理：每个所选掉落克隆自己的世界实体与 Flippy ↔ Ground 状态机；原动画、模型、VFX、依赖和原声音均保留，背包/仓库 usesound 与表格 dropsound 不改。
  • 覆盖范围：地图可选女伯爵路线或游戏数据中的全部 137 个区域；掉落可选 33 个符文、宝石与骷髅、护身符、珠宝、钥匙、器官、精华与赦免徽章。
  • 协议：v7 使用独立地点同步码与 127 个低相关掉落签名，默认增益 -30dBFS；地点标记混入原始持续环境音，主界面有独立标记用于立即结束上一场计时。
  • 生命周期：世界物品在地面持续发送时，软件用 6 秒缺席门限合并成一次掉落；捡起并在门限后再次落地可成为新事件。完全同步的多个同名物品无法从同一混合信号推断数量。
  • 落库：所选掉落先写入通用原始观测表；离开当前野外或返回主界面时，独立分段和观测归属在同一数据库事务内保存。
  • 运行诊断：状态卡实时显示音频峰值、数据包、符文、扩展物品、地点信号和最近置信度；先看峰值即可区分“没有捕获到声音”和“有声音但没有标记”。
启动方式：点击“一键准备并开启”后，工具默认生成全区域和全部支持类别；D2RHub 会复核协议清单，在保留其他无关启动参数的前提下，将目标账号的 Mod 参数固定为 -mod <新 Mod 名> -txt -assettestmode 1 并开启识别。不要同时启用源 Mod；若游戏已经运行，请重启该账号使新参数生效。

不同代码的掉落同时播放可以分别识别；同一代码在完全相同时间重叠时，只能视为一次事件。护身符、珠宝等只能识别基础代码，无法仅凭声音判断暗金、套装、品质、词缀或鉴定结果。

08 · LOCAL ANALYTICS

新版统计页与统计口径

从主界面顶部的统计按钮，或“设置中心 → 自动化 → 打开掉落统计图表”进入。统计按钮旁的“分享战报”可直接生成当前战报并复制为 PNG 图片，随后可粘贴到聊天、文档或图片编辑器。页面读取本地数据库，并通过仅监听本机回环地址的临时 API 完成刷新、重命名和删除。

底层分段与多选策略组

不同名称的野外各自开始、结束并保存独立分段；主城和主界面停止计时。统计页内置女伯爵、地穴、安达利尔、墨菲斯托、Chaos、巴尔等常用 Farm 策略组，首次使用时全部默认开启，也可同时勾选或关闭多条路线；每个预设旁都能直接编辑，修改后的预设保存在本机并可恢复系统默认。自定义策略同样支持新建、编辑和删除。每个原始分段最多归入一个策略，重叠路线不会重复计数。策略只对展示、筛选、导出和战报生效，不修改数据库中的原始分段与掉落归属；没有行程标识的旧记录不会被猜测合并。主界面快捷战报与统计 HTML 共用所选策略、预设修改、战报周期、展示字段和异常场次口径；没有保存过偏好时才使用系统默认值。

统一筛选

筛选器可折叠；时间范围、角色、场景、掉落状态和具体符文会同时作用于顶部指标、趋势、对比、热力图、符文视图、截图与明细。明细另有搜索、排序和每页 50 条分页。“优化离群场次”默认开启：先过滤短于或等于滑条阈值且没有掉落的场次，阈值默认 1 秒，可在 0–10 秒间调整；同组样本达到 10 场后，才继续处理偏离场均 10 倍以上或低于 0.1 倍的极端耗时。所有处理只影响统计结果，不改数据库。

效率与趋势

总场次、总追踪时间、平均/中位/P90/最佳用时、按日趋势、场景效率和角色对比。

掉落与时段

掉落总数、每百场掉落、高级符文、命中率、平均间隔、星期×小时热力图。

33 号符文图谱

符文层级、1–33 号密度矩阵和排行榜；点击单个符文可直接加入筛选。

管理与导出

高级符文截图画廊、单条/整场删除、场景批量改名，以及筛选后的 CSV / JSON 导出。

关键指标怎么计算

指标口径
一场 / 场次原始口径是一条已完成的野外 scene_record；启用策略后，同一行程中连续命中该策略的分段会先合并，并且整个策略组只计一场。不是一次游戏启动，也不是一次掉落。
平均 / 中位 / P90 / 最佳策略组先把组内各分段的 timer_seconds 相加，得到该场完整耗时；再对筛选后的“场”计算算术平均、50 分位、90 分位和最小值。例如一组 40 秒 + 60 秒会作为一场 100 秒，而不是两场平均 50 秒。
掉落数筛选后所有记录的 drops 数组元素总和；同场多个符文分别计数。
每百场掉落掉落数 ÷ 场次 × 100，方便不同场景样本量对比。
有掉落场 / 命中率至少一条掉落的场数 ÷ 场次；高级符文命中率则只看 #24–#33。
高级符文间隔按时间排序后，相邻“含高级符文的场”之间跨过的场次数平均值；样本不足时不显示。
截图数存在 screenshot_path 的掉落条目数量，不等同于高级符文总数。
删除不可撤销：在统计页删除整场或单个掉落会直接改写本地数据库。重要数据请先备份 %APPDATA%\D2RHub\stateData 或导出 JSON。

09 · COMPANION

Bongo Cat

在“设置中心 → 伴随”开启桌宠。猫咪会响应键盘和鼠标输入，可显示随机对话及轻量系统状态提示。

  • 拖动猫咪本体可以改变屏幕位置；右键打开皮肤、计数重置和隐藏菜单。
  • 设置中心可调整 0.5×–5.0× 缩放、气泡对话框和已解锁皮肤。
  • “法师猫咪”属于随机彩蛋解锁项；未解锁时不会出现在可选皮肤中。

10 · DATA & PRIVACY

数据位置、备份与更新

D2RHub 使用当前 Windows 用户的 %APPDATA%\D2RHub 保存运行数据；日志保存在程序可执行文件同级目录：

位置内容
%APPDATA%\D2RHub\global_config.json全局路径、界面、启动策略、快捷键、声纹与桌宠设置
%APPDATA%\D2RHub\accounts\账号元数据、DPAPI 加密 Token、Battle.net / UnifiedAuth 快照、账号游戏设置
%APPDATA%\D2RHub\stateData\data.db场次历史与通用掉落声纹观测数据库（旧符文观测会自动迁移）
logs\程序运行日志；每次启动新建，自动最多保留 16 个

从旧版便携格式升级时，程序会自动把程序同级 config 搬迁到用户数据目录；迁移失败会继续使用旧目录并在下次启动重试。如果新旧两处都已有配置、账号或统计数据，程序会保留两边而不会静默合并或覆盖，并在日志中报告冲突。

迁移或重装前，退出 D2RHub 并备份整个 %APPDATA%\D2RHub 目录；如果旧 config 仍存在或日志报告迁移冲突，请在核对完成前同时备份它。排障需要时也可一并备份程序同级 logs。不要在程序运行时手工编辑或覆盖数据库和账号快照。

程序不会在应用内替换正在运行的可执行文件。“每日检查更新”每天首次启动时检查新版本；发现更新后会打开项目 Release / 安装包页面，由你下载 MSI 或 NSIS 安装包完成升级。

D2RHub 不会主动上传账号配置、Token 或声纹统计。联网范围包括 Battle.net Token 登录页面、GitHub Releases 更新接口和邪恶区域信息接口；统计数据留在本机。

11 · TROUBLESHOOTING

疑难解答

账号无法创建或对应区服不可选

检查该客户端的游戏目录和存档目录是否成组配置。战网认证还需对应客户端的 Battle.net.exe；亚/美/欧服统一检查国际服档案。

战网初始化超时或快照失效

确认 Battle.net 已实际登录完成、路径对应正确客户端，并避免同时执行另一个战网认证操作。账号卡片显示过期或启动失败时，执行重新初始化。

网页 Token 获取页打不开

在“连接”中重新探测或手动选择 Edge / Chrome，关闭同类型浏览器后重试独立浏览器流程。也可以手动取得 Token 后回到向导粘贴。

画质设置无法读取

确认存档路径正确且包含 Settings.json。先用对应国服/国际服客户端正常进入游戏一次，再回到设置中心加载。

悬浮窗吸附后找不到

沿最近使用的屏幕边缘缓慢移动鼠标，触发边会让窗口抽出。仍无法找到时，在“显示”中关闭再开启悬浮窗，或重启应用。

迷你窗无法变成单行

继续从底边向上压缩；到 36 逻辑像素附近会切换为单行，并可降至 18。Windows 缩放比例会影响物理像素，不影响逻辑阈值。

声纹无数据或识别不稳定

确认账号使用的是独立工具最新输出的组合 Mod、启动参数包含完整的 -mod <名称> -txt -assettestmode 1、游戏音效未静音、目标账号和运行中的 D2R 一致。Mod 实际发出的类别由工具的 --track 决定；D2RHub 设置只过滤接收后要记录的类别。先看“音频峰值”，再看“地点信号”和掉落计数；日志会提示当前 Mod 清单缺失或协议版本不兼容。

进一步排查

从“维护 → 打开日志”查看最新日志。提交 Issue 前删除 Token、Windows 用户名、个人路径和含敏感画面的截图；安全问题请通过项目安全政策私下报告。
