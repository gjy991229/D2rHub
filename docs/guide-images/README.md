## 标注与维护

原始 PNG 为 1280×720。`guide-figures.js` 通过 SVG `viewBox` 裁切，并以原图坐标绘制编号与框选；不修改原始图片。编号可点击单独强调，支持打开原图。多图步骤通过上方按钮切换，只挂载当前图示。

- 重新截图后，同步更新 `guide-figures.js` 中的裁切、框选和说明，并逐一核对按钮指向。
- 裁切需包含标注框及编号圆点，避免截断文字或操作按钮。
- `example.html` 复用同一组件，提供 Mod 加工图示的独立预览。
- 运行 `npm run check:guide`，确认手册引用与 Tauri 打包资源一致。当前手册使用 11 张原图，随应用打包，可离线查看。

`mod-processing-annotated.png` 和 `room-rules-annotated.png` 是早期静态标注稿，未被当前手册引用或打包；维护当前图示时以原图与 `guide-figures.js` 为准。
