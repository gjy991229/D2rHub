# 桌宠装扮视觉审核 · 2026-09-14

本轮依据用户明确要求进行了实际浏览器视觉审核。预览直接导入生产代码中的 `PetAvatar`、`PetAccessory`、`PetCirclet` 和 `PetStage`，并非另画一套效果图。未运行通用测试套件，也未构建或替换桌面程序。

## 覆盖范围

- 19 件装扮逐件查看 `up / left / right` 三帧，共 57 个单件状态，另加基础猫咪三帧。
- 四套跨部位混搭，每套三帧，共 12 个组合状态。
- 1× 全量复核；混搭检查 0.5×、2×，以及浅色/深色背景。
- 将实际计数牌纳入组合审核，确认数字不被披风、围巾或项坠遮挡。

## 发现并修正

1. **本体与装扮坐标不一致。** 原始本体画布分别为 208×133、195×133、201×135；统一指定图像宽高会触发比例适配和留白。新增 `petGeometry.ts`，使用 208×135 的共同画布，按每张图片原始尺寸在左上角绘制。眼镜直接使用各帧实际眼睛坐标。原始本体 SVG 路径未改动。
2. **披风与颈饰遮住计数。** 新增共用的 `PetStage`，将计数牌放在装扮和动作标记下方，预览与真实桌宠使用同一布局。
3. **披风看起来像垫子。** 改为左右垂落的后景衣摆，随身体帧位移；调整圣徽及星纹到可见部位，避免被本体覆盖。
4. **旅人兜帽看起来像头箍。** 加入完整布料帽顶、尖顶和缝线，保留脸部空间。
5. **身边饰物与抬起的爪子过近。** 符文、魔典和幽灵上移，与手部留出间隔，仍保留输入帧的轻微位移。
