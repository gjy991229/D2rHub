# D2RHub v0.9.105

- Mod 下载与更新改为 Mod 管理中的同级页面，取消嵌套弹窗，修复高度超出与双层滚动问题。
- 统一软件安装包、Mod 下载、生成加工及后台任务的进度条样式，使用随主题变化的细圆角进度条。
- 下载或校验 Mod 后立即在对应按钮附近显示状态、进度与取消入口；开始操作时自动露出进度区域，离开页面后仍可从后台任务继续查看。
- 加工器已安装且为当前版本时，加工页不再重复展示下载卡片。缺失、不兼容或有已知更新时仅显示简洁提示。
- 打开设置、进入加工页或下载页只读取本地状态，不再每次访问都联网检查；每日自动检查与手动检查仍保留。
- 界面统一使用“Mod”称呼，移除“官方 Mod”措辞。

本版本沿用现有加工器与三个 Mod 资源，不重复发布未变化的资源包。
