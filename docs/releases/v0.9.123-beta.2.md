# v0.9.123-beta.2 本地测试版

- 统计总览新增按日选择的战斗日历、可展开的掉落类别、角色时间占比。
- 战报指标可选择累计战斗时间、掉落数量、高级符文和每小时掉落，旧场次配置自动适配。
- 启动后等待首次有效入场信息，启动音效不会直接启动计时。按本次选择保留仅主城和主界面声纹，离开后的判定等待仍为六秒。
- 主城暂停保留累计时间显示。识别设置提供秒、分与秒、时分秒三种显示格式。
- 声纹配方 r7 在原生主界面背景预设中增加独立发声组件，主界面信号优先于背景中的主城信号。
- 主城和主界面水印使用 20.1–21.5 kHz 频段，默认幅度上限降低到 -40 dBFS。接收端兼容原有频段。

请关闭游戏后通过 Hub 启动，使旧加工成品升级到 r7。中途在野外首次启用监听时，需要先回一次主城建立状态。主界面发声组件的游戏内覆盖和设备上的实际可听程度需要本地复测。
