# v0.9.124

- **Mod 加工**　安装包内置加工器 1.4.0-beta.27。单项和批量加工可选 JCY 高清背包与仓库，包含内嵌方盒。首次生成或升级旧配方时下载并校验预设，后续可复用本机缓存。支持复用已加工的当前配方。
- **账号与启动**　改进账号卡片、批量选择、启动队列和迷你面板。初始化向导按地区检查游戏与存档路径，创建账号时校验系统游戏设置，再保存账号快照。
- **窗口布局**　启动方案可引用已保存布局。旧方案内嵌的布局会迁移到布局列表，按账号绑定的窗口在调整启动顺序后仍使用原位置。改进布局检查、显示器预览与恢复提示。
- **跟房与统计**　新增“超级迪亚波罗”分房模式，可让多个账号在后台依次创建独立房间。快捷面板支持复制、粘贴房名、密码与序号。统计浮窗显示崔凡克及混沌魔殿的场次和平均耗时，跨场景合并同类掉落并高亮新掉落。
- **设置与界面**　维护页新增账号配置检查与修复，支持从有效备份恢复并留存原件。重整设置导航和 Mod 管理界面，新增减少界面动效的选项，更新使用手册、关于页和赞助名单。
