# D2RHub v0.99.106

- 优化 Hub 内安装包下载窗口的进度显示，统一使用主题色圆角进度条，并在附近显示下载状态和百分比。
- 未安装兼容加工器时，点击 Mod 加工入口会进入下载页；加工页同时提供“下载加工器”按钮，安装后返回即可继续。
- 资源卡片隐藏内部文件路径、安装目录和 Mod 安装版本记录，保留“打开目录”入口。
- Mod 按 NullHub、BoHub、LiteHub 排序，分别显示约 300、500、800 MB 内存参考值；实际占用随场景和设置变化。
- 资源兼容清单覆盖本次 0.99.106 版本，同时保留 0.9.104、0.9.105 客户端支持；加工协议及资源文件未变，不重复下载或发布未变化的资源包。

本版本使用版本号 0.99.106，旧版可通过软件更新升级。保留旧版资源清单与资源文件，未修改用户已有的 Mod。
